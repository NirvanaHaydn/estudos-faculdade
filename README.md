# 🎓 Estudos — Análise e Desenvolvimento de Sistemas

Repositório criado para registrar minha trajetória acadêmica no curso de **Análise e Desenvolvimento de Sistemas (ADS)**, reunindo anotações, exercícios, atividades práticas e projetos desenvolvidos ao longo da graduação.

Este repositório funciona como um registro da minha evolução em programação, desenvolvimento de software, dados, redes, interação e outras áreas da computação.

---

## 📚 2º Período — 2026/2

### 💻 Desenvolvimento e Computação

| Disciplina | Conteúdos principais |
|---|---|
| **Algoritmos e Estruturas de Dados** | Algoritmos, estruturas de dados e resolução de problemas |
| **Desenvolvimento Web Back-End** | Desenvolvimento de aplicações e serviços no back-end |
| **Design de Interação** | Interação humano-computador, usabilidade e experiência do usuário |
| **Engenharia de Requisitos de Software** | Requisitos, elicitação, análise e especificação de software |
| **Fundamentos de Redes de Computadores** | Redes, protocolos, comunicação e infraestrutura |
| **Manipulação de Dados com SQL** | Consultas, manipulação e gerenciamento de dados utilizando SQL |
| **Modelagem de Dados** | Modelagem conceitual, lógica e estruturação de bancos de dados |
| **Programação Modular** | Funções, procedimentos, modularização, TADs e programação orientada a objetos |

### 🧠 Formação e Competências

| Disciplina | Área |
|---|---|
| **Competências Comportamentais: Liderança** | Liderança, comunicação, colaboração e desenvolvimento profissional |
| **Desafios Contemporâneos: Sociedade, Diversidade e Ética** | Sociedade, diversidade, ética e responsabilidade |
