# 💻 Programação Modular

Disciplina do **2º período — 2026/2** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

A Programação Modular aborda técnicas para construção de sistemas **escaláveis, adaptáveis, reutilizáveis, corretos e seguros**, utilizando a decomposição de sistemas em módulos e os princípios da **Programação Orientada a Objetos (POO)**.

---

## 🎯 Objetivos da disciplina

Ao longo da disciplina, serão estudados conceitos relacionados ao desenvolvimento de sistemas modulares e à qualidade de software, com foco em:

- Modularização de sistemas
- Programação Orientada a Objetos
- Modelagem de entidades e relacionamentos
- Encapsulamento e ocultação de informações
- Herança e polimorfismo
- Interfaces e tipos genéricos
- Programação orientada a eventos
- Princípios SOLID
- Padrões de projeto
- Aspectos funcionais das linguagens de programação
